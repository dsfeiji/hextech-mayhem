# 海克斯大乱斗 (hexmayhem)

Minecraft **1.21** / Fabric / Java **21**。我的世界版海克斯大乱斗：三个职业 + 三选一海克斯强化。
**所有海克斯所有职业都能拿，效果完全一样**；职业差异只来自基础属性和初始装备。

## 开发

- `gradlew.bat build`：产物在 `build/libs/hexmayhem-0.1.0.jar`
- `gradlew.bat runClient` / `runServer`：开发环境启动
- IntelliJ 直接运行 “Minecraft Client” 即可。本机只有 JDK 25，所以 Fabric Loader 用 0.19.5（旧版 0.15.x 不支持 Java 25 会启动崩溃）。

## 游戏流程

1. 管理员输入 `/hex start`：先给所有人弹出**自定义房间**（仿英雄联盟自定义对局，`game/HexLobby` + `client/LobbyScreen`）。左蓝右红各 5 个位置，点击空位加入，“移至待定”退出位置；房主（执行 `/hex start` 的人）和管理员可以“随机分队”、悬停别人的位置点 × 把他移到待定区、“解散房间”、“开始游戏”。开始时待定区的玩家自动补到人少的一方，两边都至少要有一人（只有一名玩家时可以直接开始，方便测试）。房间界面 Esc 关闭、按 H 重新打开。开始后写入原版队伍 `hex_blue` / `hex_red`（禁止友伤），然后清空所有在线玩家背包、开启死亡不掉落，弹出职业选择。对局中途加入的玩家自动分到人少的一方；`/hex stop` 删除这两个队伍，并把玩家放回开局前所在的原版队伍。
2. **按经验等级选海克斯**：开局所有人设为 1 级，立刻获得一次三选一；之后 7 级、11 级、15 级各一次（一次升多级会依次排队）。每次的品质都随机：白银 20%、黄金 50%、棱彩 30%（`HexGame.randomTier`）。**升级获得的海克斯要阵亡一次才解锁**（类似英雄联盟海克斯大乱斗）：活着达到等级时只提示，死亡后解锁并自动弹出三选一；解锁后复活走出去也能随时按 H 继续选。阵亡期间升到对应等级（例如靠助攻）获得的海克斯直接解锁。开局 1 级的和 `/hex offer` 发放的不受限制，立刻可选。升级用原版经验：打怪 / 挖矿等原版经验、击杀玩家 +40 点、助攻 +15 点，另外每 5 秒被动 +3 点（约 2 分半到 7 级、5 分钟到 11 级、8 分半到 15 级）。每升 1 级最大生命 +0.5、攻击力 +0.1（相对 1 级计算；数值在 `HexGame` 的 `HEALTH_PER_LEVEL` / `DAMAGE_PER_LEVEL` / `PASSIVE_XP_*`，击杀经验在 `HexStats`）。
3. 选择界面可以 Esc 关闭，按 **H** 重新打开。每局可刷新 2 次。
   **复活时间**：对局中原版规则改为立即重生（`doImmediateRespawn`），由本模组控制复活时间——死亡后变成旁观模式留在死亡地点（画面变灰、中间显示倒计时和进度条），时间到后回到重生点、变回生存并回满状态。复活时间 = 4 秒 + 每级 2.5 秒，最多 50 秒（1 级 4 秒、7 级 19 秒、11 级 29 秒、15 级 39 秒、19 级起 50 秒；数值在 `HexRespawn`）。阵亡期间海克斯效果不生效，Tab 战绩表里该玩家整行变暗并显示剩余秒数；下线后倒计时暂停、上线继续；`/hex stop` 会让所有阵亡玩家立即复活。
4. 左上角 HUD 显示职业、已有海克斯（含叠层）、已激活套装、当前等级和下一次海克斯需要的等级；Tab 战绩表的职业图标右下角显示每个人的等级。
5. `/hex stop` 结束对局并清空所有人的职业和海克斯。
6. **模组开关 = 对局是否进行中。** 没有进行中的对局时（`/hex stop` 之后、或从未开始），海克斯效果、战绩统计、击杀播报全部停止，客户端不显示任何本模组界面（血条恢复原版爱心、没有头顶血条 / 右上角战绩 / 击杀播报 / Tab 战绩表 / 海克斯列表，H 键无效）；`/hex role|offer|give|remove` 会被拒绝。结束时收回时光沙漏，并把 keepInventory、doImmediateRespawn 恢复成开局前的值。职业初始装备是原版物品，不会收回。

中途加入的玩家会补发已错过的选择。对局状态随世界保存。

## 界面

- **ModernUI**（推荐安装，客户端需要 ModernUI-Fabric 和 Forge Config API Port）：职业选择、海克斯三选一使用 ModernUI 卡片界面（背景模糊、悬停浮起、圆形图标徽章）。没装 ModernUI 时自动回退到原版风格界面，功能相同。
- **海克斯图标**：默认用原版物品 / 状态效果贴图（映射在 `client/HexIcons.java`）。想换成自定义图标，把正方形 png 放到 `assets/hexmayhem/textures/hex/<海克斯id>.png` 即可自动替换（职业图标为 `role_warrior` / `role_tank` / `role_archer`）。
- **血条**：对局中（已选职业，生存 / 冒险模式）底部爱心换成一整条血条，显示 `当前+吸收 / 最大`，每 10 点一道刻度、每 50 点一道长刻度，掉血有残影；中毒变绿、凋零变灰、冰冻变蓝。
- **战绩**：右上角显示 己方击杀 ⚔ 敌方击杀、对局时间和自己的 K / D / A（有状态效果图标时自动下移）。对局中按住 **Tab** 显示全体战绩表（代替原版玩家列表，期间隐藏聊天栏）：己方 / 敌方分组，每人显示职业、名字、全部海克斯图标、K / D / A 和对玩家伤害。助攻 = 死亡前 10 秒内对他造成过伤害；摔死等情况击杀归给 10 秒内最后伤害他的玩家。
- **击杀播报**：每次有玩家死亡，屏幕上方显示“[图标] A 击杀了 B [图标]”和助攻人数，右侧战绩框下方保留最近 5 条击杀记录（8 秒），己方蓝色、敌方红色。特殊击杀显示大字并播放音效：第一滴血、双杀、三杀、四杀、五杀（和英雄联盟一样，两次击杀间隔 10 秒内算连续，第五杀放宽到 30 秒）、终结（击杀正在连杀 ≥3 的玩家）；连杀称号：大杀特杀(3) / 主宰比赛(4) / 无人能挡(5) / 横扫千军(6) / 接近神了(7) / 超神(8+)，死亡后清零。
- **头顶血条**：其他玩家头顶显示血条，**同一个原版队伍（`/team`）为蓝色，其余为红色**。会被方块遮挡，不能透视。48 格内显示。

## 命令

| 命令 | 说明 |
|---|---|
| `/hex start` / `/hex stop` | 开始 / 结束对局（管理员） |
| `/hex role <warrior\|tank\|archer> [玩家]` | 强制设置职业，不发装备（管理员） |
| `/hex offer <silver\|gold\|prismatic> [玩家]` | 发放一次三选一（管理员） |
| `/hex give <海克斯id> [玩家]` / `/hex remove ...` | 直接给予 / 移除海克斯（管理员，测试用） |
| `/hex reset [玩家]` | 清空职业和海克斯（管理员） |
| `/hex info [玩家]` | 查看已有海克斯 |
| `/hex list` | 列出全部海克斯和 id |

## 职业

| 职业 | 属性 | 初始装备 |
|---|---|---|
| 战士 | 攻击力 +2 | 铁剑、铁胸甲 |
| 坦克 | 最大生命 +10、护甲 +4、击退抗性 +20%、移速 -10% | 石剑、盾牌、铁胸甲、铁护腿 |
| 弓箭手 | 最大生命 -4、移速 +10%、拉弓速度 +25% | 弓、64 箭、木剑、皮革胸甲 |

## 代码结构

- `hex/Hexes.java`：**全部海克斯定义**（名称、描述、属性修改）和套装。纯属性类海克斯只需在这里加一行。
- `game/HexCombat.java`：机制类效果——伤害加成、命中效果、反伤、免死、击杀叠层。
- `game/HexGame.java`：对局流程、发放时间表（`OFFER_TIMES`）、属性刷新、每刻效果（珍珠/风弹补给、监守者音波、拉弓加速等）。
- `game/Role.java`：职业属性和初始装备。
- `mixin/`：`LivingEntity.hurt` 伤害钩子、近战暴击倍率、使用物品计时。
- 客户端：`CardScreen`（卡片界面）、`HexSelectScreen`、`RoleSelectScreen`、`HexHud`。

## 说明

- “攻击”包括近战和箭矢命中，所以所有命中类海克斯对弓箭手同样有效。
- 范围效果（音波、爆炸、多重打击）只命中非队友玩家和敌对生物。
- 击杀叠层目前统计所有生物击杀（便于单人测试），正式 PVP 可改为只算玩家：`HexCombat.onKill`。
